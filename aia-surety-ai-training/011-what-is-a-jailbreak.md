# What is a jailbreak?

An attempt to make a model bypass its restrictions.

- Change the framing.
- Claim different authority.
- Ask indirectly for the restricted output.

**Today’s challenge: a fictional secret in a toy chatbot.**

## Speaker notes

Explain the term before discussing techniques. A normal request to change tone is not a jailbreak. The key is attempting to cross an established behavioral boundary.

Our exercise illustrates a custom instruction boundary. It is not a measurement of a vendor's complete security architecture or a demonstration involving real credentials.

Later we will meet indirect prompt injection: a legitimate task is redirected by instructions inside something the system reads. The concepts overlap, but the attacker’s entry point matters.
