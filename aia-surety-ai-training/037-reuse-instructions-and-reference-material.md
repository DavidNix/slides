# Reuse instructions and reference material

A project can bring together:

- A recurring task and its instructions.
- Relevant reference documents.
- Related conversations and outputs.

**Convenience grows when context is reusable. So does the need to manage access.**

## Speaker notes

Both ChatGPT and Claude offer projects with instructions and reference material. Exact capabilities, memory behavior, sharing, and limits depend on the product, plan, and workspace settings.

Show where the presenter’s account stores project instructions and sources. Name the demonstration project “Fictional submission review.” Add only the demo checklist and records.

Explain retrieval in plain language: an application can find relevant passages and place them into the model's context. This is often called retrieval-augmented generation, or RAG. It supplies information at answer time; it does not guarantee that the right passage is found or interpreted correctly.

Assign an owner to real reference material so obsolete procedures are replaced. Sharing a project can expose its files and outputs to additional people. Making everything searchable is a permission decision.
