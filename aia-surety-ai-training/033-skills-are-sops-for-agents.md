# Skills: SOPs for agents

A skill is a packaged procedure the agent loads when a task matches:

- Instructions for one kind of work, plus optional templates and reference files.
- Written once, kept somewhere the agent can reach.
- Pulled in only for the tasks it covers, like an SOP pulled from the drawer.

**A skill is an SOP the agent can read: same procedure, same output, every time.**

## Speaker notes

Every department has SOPs: how to summarize a claim file, check a submission, format a letter. A skill is that SOP, written for the agent. Nobody re-explains the procedure each time.

Premade skills ship with the product, such as Excel and Word. Ask for a workbook and the agent uses the Excel skill.

If asked: **skills tell the agent how to do the work. Connectors give it access to a system.**

Transition: "Skills can be shared or private, and they do not fill up the window."
