# Video: watch the agent work

A trucker says it delivered furniture and is owed $4,800. The broker's records name a different trucking company and price. The examiner has already asked three parties questions, and all three replied.

The agent gets one prompt:

- Read the claim and the replies.
- Build an evidence spreadsheet.
- Draft follow-ups only for what is still open.
- Prepare a short case note for the examiner.

**We start the work now and come back to the results after verification.**
