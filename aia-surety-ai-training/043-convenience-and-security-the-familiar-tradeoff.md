# Convenience and security: the familiar tradeoff

![A balance scale contrasts security with convenience.](../2026-09-ai-security/security-vs-convenience-scale-labeled.png)

**Broader access + fewer checkpoints → greater exposure.**

## Speaker notes

Make this a central point of the session. A master key is convenient because it opens every room. Losing it has a larger consequence than losing a key to one cupboard. AI does not change that basic security principle.

Connecting a mailbox, a file store, and a sending tool removes manual steps. It also makes more information and actions reachable through one system. Automatic execution removes a checkpoint that might have caught a mistake.

The tradeoff is strongest when convenience comes from wider permissions, persistent access, unattended execution, or reduced review. It is not a mathematical claim that every usability improvement weakens security: a well-designed approved workflow can improve both.

Repeat the key question: **“What did we make easier, and what can now go wrong?”** The purpose is to choose the tradeoff deliberately and add controls proportional to the consequence.
