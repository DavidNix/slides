# The convenience ladder

| More convenience | More at stake |
| --- | --- |
| Draft from selected text | Accuracy of the draft and handling of that text |
| Search internal records | Access to additional information |
| Send messages and update records | External disclosure and changed business data |
| Work unattended across systems | Repeated mistakes and delayed detection |

**Every additional capability deserves an explicit decision.**

## Speaker notes

Walk through the order-status task from the agent section at each level. First a person chooses the text. Next the agent looks up the order. Then it emails the customer. Finally it answers every customer without a person watching.

Risk depends on the data, permissions, actions, and controls; these rows are not a universal numerical risk score. A draft containing sensitive information can already be high consequence.

Scale matters. An incorrect sentence in a draft is easy to revise. The same error automatically sent to hundreds of recipients is harder to recover from.

Ask: “Which rung would be useful for your team today?” Separate the value of assistance from the desire to automate every subsequent step.
