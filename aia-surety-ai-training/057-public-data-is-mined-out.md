# Public data is mined out. You're the next source.

- **Every ML system you've used was built from collected examples.** Spam filters learned from labeled emails; speech recognition from recordings; translation from parallel texts.
- **LLMs took it to full scale:** they learned language from a huge slice of the public internet. There is no ChatGPT without that data.
- **The free supply is running out,** so labs are turning to licensed archives, user conversations, agent sessions, and workplace documents.

**The internet was the easy ore. Now labs are digging into user conversations — including yours.**

## Speaker notes

Machine learning has been "learning from data" since the beginning: every earlier system in daily life — spam filters, search ranking, speech recognition, machine translation — was built from collected examples. What changed with LLMs is scale: instead of curating examples, labs trained on a huge slice of the public internet — web pages, books, code, forums. The models are that data, rearranged by training. Remove the internet's text and there is no GPT.

That is why the courtroom record on the previous two slides exists: data is the asset everyone is racing for, and the courts have now put a price on it. Public web data is largely mined — scraped, litigated, or running out — so the new sources are licensed archives, user conversations, agent sessions, and workplace documents. View the default-on training settings through this lens: your conversations are being collected as training material right now, whether or not you intended to donate them.

Transition: "Which brings the question home: what happens to your data?"
