# Give AI a clear brief

**Task + sources + boundaries + output + checks**

> Compare this submission with the attached checklist. Return a table of required, received, and missing items. Cite the source for each finding. Flag contradictions. Draft a short follow-up for my review.

## Speaker notes

Good instructions resemble good delegation to a colleague. Give the outcome, relevant context, constraints, and a definition of a useful result.

Ask for missing information to be visible. Ask for evidence you can inspect rather than relying on a confident explanation.

Improve the result iteratively: “This is too long,” “Use the terminology in the procedure,” or “Which line supports that finding?” Verify the answer against the actual source.

Take one task mentioned at the start and have the room turn it into a brief using the five-part pattern.

Prompt instructions such as “draft only” are useful guidance. For an agent with sending tools, enforce that boundary in software too.
