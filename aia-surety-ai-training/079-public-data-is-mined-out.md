# Public data is mined out. You're the next source.

- **Every ML system you've used was built from collected examples.** Spam filters learned from labeled emails; speech recognition from recordings; translation from parallel texts.
- **LLMs took it to full scale:** they learned language from a huge slice of the public internet. There is no ChatGPT without that data.
- **The free supply is running out,** so labs are turning to licensed archives, user conversations, agent sessions, and workplace documents.

**The internet was the easy ore. Now labs are digging into user conversations, including yours.**

## Speaker notes

Machine learning has always learned from collected examples. LLMs changed the scale: they trained on a huge slice of the public internet. Remove that text and there is no GPT.

Public web data is mostly used up. The new sources are licensed archives, user conversations, agent sessions, and workplace documents. Default-on training settings collect your conversations now.
