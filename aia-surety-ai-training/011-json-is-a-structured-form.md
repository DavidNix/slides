# JSON is a structured form

```json
{
  "submission_id": "S-1042",
  "applicant": "Cedar Bridge Services",
  "received_documents": ["signed_application"]
}
```

- Left side: the field name.
- Right side: its value.
- Square brackets: a list.

**You already read forms like this.**

## Speaker notes

Read the example aloud in ordinary language. “The submission ID is S-1042. The applicant is Cedar Bridge Services. We received one document.”

JSON is a data format. It does not execute an action by itself. Software has to interpret it and perform the operation.

An API is a defined way for programs to exchange requests and results. We will see JSON used both to describe a tool and to request its use.

Give the room permission to follow the meaning without memorizing punctuation.
