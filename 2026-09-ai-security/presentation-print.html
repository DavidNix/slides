What is a model?

GPT-5.6 Sol · Claude Opus 5 · Claude Fable 5.1

It's a JSON API. That's all it is.

Tokens in → tokens out. No memory, no self, no intent.

{"model": "gpt-5.6-sol",
  "choices": [{
    "message": {
      "role": "assistant",
      "content": "Hello! How can I help?"
    }
  }],
  "usage": {
    "prompt_tokens": 24,
    "completion_tokens": 12
  }
}
key insight

Models are stateless

Frozen in time. Tokens in, tokens out.

Models cannot distinguish content from instructions.

What could go wrong?

mythbusting

The #1 threat is not giving your IP to an AI lab

Not Anthropic. Not OpenAI. Not China "stealing your data to train."

That's a real concern, but it's not the attack you should lose sleep over.

real incident

Data Exfiltration

An agent with tools and a bit of untrusted input can quietly ship your files somewhere they shouldn't go.
